> **Transform code into understanding.**

Manifestum is an open-source code intelligence platform developed by **Aevum Labs**.

Its mission is to help developers understand, search, analyze, and navigate complex software systems through deterministic analysis, knowledge graphs, and AI-assisted engineering.

---

# Status

🚧 **Pre-Alpha**

Manifestum is currently under active development.

The architecture is being built before implementation to create a scalable, maintainable, and contributor-friendly engineering platform.

---

# Mission

Software continues to grow in complexity.

Developers spend countless hours trying to answer questions like:

- Where is this function called?
- How does authentication work?
- Which files depend on this module?
- What breaks if I change this code?
- Which services communicate together?
- What parts of the project are undocumented?

Manifestum exists to answer those questions.

---

# Vision

Manifestum aims to become an **Intelligent Engineering Operating System** capable of transforming any software repository into structured engineering knowledge.

Instead of manually reading thousands of files, developers will be able to explore and understand an entire codebase through intelligent analysis.

# Engineering Principles

Manifestum is guided by five principles.

## Deterministic Before Generative

Reliable engineering comes before AI generation.

## Open Architecture

Components should be modular and replaceable.

## Explainability

Every conclusion should trace back to evidence inside the repository.

## Community First

Great engineering grows through collaboration.

## Build for the Long Term

Build systems that remain useful for years—not just demos.
